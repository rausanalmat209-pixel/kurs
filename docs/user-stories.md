# CareerMap — User Stories

| ID | User Story | MoSCoW | Тексеру шарты |
|---|---|---|---|
| US-1 | Студент ретінде мен Қазақстан университеттерінің тізімін көргім келеді, себебі өзіме қажетті университетті таңдауым керек. | M | Университеттер тізімі ашылады. |
| US-2 | Талапкер ретінде мен университеттерді салыстырғым келеді, себебі өзіме қолайлы оқу орнын тапқым келеді. | M | Екі немесе одан да көп университетті салыстыруға болады. |
| US-3 | Студент ретінде мен мамандықтар туралы ақпарат алғым келеді, себебі болашақ мамандығымды дұрыс таңдағым келеді. | M | Мамандықтар туралы ақпарат көрсетіледі. |
| US-4 | Қолданушы ретінде мен сайттың тілін өзгерткім келеді, себебі ақпаратты өзіме ыңғайлы тілде оқығым келеді. | S | Қазақ, орыс және ағылшын тілдерін таңдауға болады. |
| US-5 | Университет өкілі ретінде мен университет туралы ақпаратты жаңартқым келеді, себебі талапкерлерге дұрыс ақпарат ұсынғым келеді. | M | Ақпаратты өзгертіп, сақтауға болады. |
| US-6 | Қолданушы ретінде мен университеттерді таңдаулы тізімге сақтағым келеді, себебі кейін қайта қарағым келеді. | C | Таңдалған университет сақталады. |

## MVP шегі

- **Must:** US-1, US-2, US-3, US-5
- **Should:** US-4
- **Could:** US-6
- **Won’t:** Бұл нұсқада қосымша функциялар қарастырылмайды
