# Қадам жобасының қабат картасы

| Қабат | 1-әрекет: не істейді? | 2-әрекет: не істейді? |
|---|---|---|
| Router | Ойын туралы сұранысты қабылдайды | Қолданушы профилін ашады |
| Schema | Қолданушы мәліметтерін тексереді | Жауап форматын анықтайды |
| Service | Ойын логикасын басқарады | Тапсырмаларды өңдейді |
| Repository | Қолданушы деректерін алады | Ойын нәтижелерін сақтайды |
| Model | Қолданушы кестесі | Ойын нәтижелері кестесі |
| Қате-HTTP | Қате сұранысты анықтайды | Қате туралы хабарлама береді |

## Біздің ереже

- Router-де SQL жазылмайды.
- Service ішінде HTTPException қолданылмайды.
- Құпия ақпарат тек .env файлында сақталады.
